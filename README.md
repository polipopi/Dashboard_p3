# Pulse · Dashboard P3

Dashboard interactivo desarrollado con **React, TypeScript, Vite y Recharts**.

## Características
- Indicadores KPI de ingresos, pedidos, clientes y ticket promedio.
- Gráfico de ingresos y visitantes con filtros de 7, 30 y 90 días.
- Visualización de fuentes de tráfico.
- Tabla de transacciones con búsqueda.
- Exportación de transacciones a CSV.
- Actualización automática de la hora.
- Diseño responsive para escritorio y móvil.

> Los datos son ficticios y sirven para demostrar la interfaz. No representan información comercial real ni una conexión a una API externa.

## Instalación
```bash
npm install
npm run dev
```

## Compilar
```bash
npm run build
```

## Publicación
El proyecto se despliega automáticamente en GitHub Pages mediante GitHub Actions al hacer push a `main`.

URL: https://polipopi.github.io/Dashboard_p3/

En GitHub, verifica en **Settings → Pages** que la fuente esté configurada como **GitHub Actions**.
